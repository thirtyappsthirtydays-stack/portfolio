The challenge

One app a day, for a real problem

To see how AI is changing the way products get built, I set myself a challenge: 30 small web and mobile apps in 30 days, each one built with AI coding tools to solve a real problem.

Tools
10+ AI development tools, from prompt-to-app builders to AI code editors
Pace
Each app designed, prototyped and iterated in under 24 hours

How I worked

Start from a problem, then write it down

Before any prompting, I wrote a short PRD for each app: the problem, the user flow and the core features.

One app, one day
  1. Notice a problem
  2. Write a short PRD
  3. Build with an AI tool
  4. Revise the PRD and iterate
  5. A working prototype
I often drafted the PRD with AI, then edited it, and revised it several times as each app took shape.
